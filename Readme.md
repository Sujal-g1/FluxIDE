## 💡 About Flux

Learning programming is often a fragmented experience.

A student writes code in an editor, watches YouTube tutorials to understand concepts, searches Google or Stack Overflow to fix errors, and uses AI tools to understand unfamiliar code.

This constant switching between platforms makes learning difficult. More importantly, students sometimes manage to fix errors or complete projects without actually understanding what they have written.

**What if the environment where you write code could also teach you how to code?**

That's the idea behind **Flux**.

Flux is a learning-focused IDE that aims to bring coding, learning, debugging, and AI-powered guidance into a single environment.

Instead of simply generating code or automatically fixing errors, Flux focuses on helping students understand their code, learn from their mistakes, and develop the ability to solve programming problems independently.

## 🎯 Our Vision

Our vision is to make programming more accessible, interactive, and easier to understand for students and beginners.

We want to create an environment where a student can:

- Write code and understand what they are writing.
- Learn programming concepts in the context of their actual code.
- Understand why errors occur instead of blindly fixing them.
- Receive guidance when stuck rather than always receiving complete solutions.
- Build projects while learning the concepts behind them.
- Gradually develop independent coding and problem-solving skills.

**The goal is not to make students dependent on AI. The goal is to help them become developers who can think, write, debug, and solve problems independently.**

## 🚀 Why Flux?

Consider a student learning JavaScript or React for the first time.

They start writing code, encounter an error, and don't understand what went wrong.

The usual process involves:
1. Searching the error on Google.
2. Watching tutorials to understand the concept.
3. Asking ChatGPT for an explanation.
4. Trying different solutions.
5. Returning to the editor and testing the code again.

Sometimes the problem gets solved, but the underlying concept remains unclear.

Flux aims to make this experience more connected.

Imagine encountering an error inside your editor and being able to understand:

- What exactly went wrong?
- Why did this happen?
- Which programming concept is involved?
- How can I approach fixing it?
- What should I learn from this mistake?

Rather than treating errors as obstacles, Flux aims to turn them into learning opportunities.

## 🧠 Our AI Philosophy

We believe there is a significant difference between helping someone complete a coding task and helping them understand programming.

AI in Flux should act as a learning companion, not just a code generator.

Our approach follows three principles:

### Explain → Guide → Empower

**Explain:** Help students understand the problem, the error, and the programming concepts behind it.

**Guide:** Provide hints, suggestions, and possible approaches instead of immediately revealing complete solutions.

**Empower:** Encourage students to apply what they have learned and solve similar problems independently.

The ultimate objective is to gradually reduce the student's dependence on AI as their programming knowledge improves.

---

## 🎨 Design Philosophy

Flux is being designed around simplicity, clarity, and usability.

The interface follows a minimal, dark, developer-oriented visual language while keeping the experience approachable for beginners.

Key design principles:

- **Simplicity:** Avoid unnecessary complexity and distractions.
- **Clarity:** Keep navigation, tools, and interactions easy to understand.
- **Consistency:** Maintain a consistent visual language across the workspace.
- **Focus:** Give priority to the coding and learning experience.
- **Accessibility:** Make the environment approachable for students with different levels of programming experience.
