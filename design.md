# Flux IDE — Product & Design Document

## 1. Overview

**Flux** is a learning-focused Integrated Development Environment (IDE) designed to help students learn programming by writing, understanding, and debugging code.

Unlike traditional development environments that primarily focus on developer productivity, Flux aims to make the coding environment an interactive learning space.

**Core Idea:** Learn to code by coding.

## 2. Vision

Build an IDE where students don't just write code or receive AI-generated solutions. They understand what they are writing, learn from their mistakes, and gradually become independent developers.

Flux aims to reduce the need to constantly switch between code editors, video tutorials, documentation, search engines, and AI chat tools while learning programming.

## 3. Target Audience

- Beginners learning programming for the first time.
- College students learning programming languages and concepts.
- Students learning web development and modern technologies.
- Developers who want to strengthen their programming fundamentals.

**Primary Focus:** Students and beginners learning web development.

## 4. Design Philosophy

Flux follows four core principles:

1. **Learning over productivity:** Prioritize understanding concepts over generating code quickly.
2. **Simplicity:** Keep the interface clean, intuitive, and beginner-friendly.
3. **Guidance over automation:** Help students solve problems instead of automatically solving everything for them.
4. **Learning through mistakes:** Treat errors as opportunities to understand programming concepts.

## 5. Core Features

### Code Editor
- Code editing with syntax highlighting.
- File and folder management.
- Project workspace.
- Integrated terminal and code execution.
- Support for programming languages and frameworks.

### AI Learning Assistant
- Explain code in beginner-friendly language.
- Answer programming-related questions.
- Explain unfamiliar concepts within the current project.
- Provide contextual guidance while coding.

### Intelligent Error Assistance
- Explain what went wrong and why.
- Identify the programming concepts behind errors.
- Suggest possible approaches to fixing mistakes.
- Help students understand errors instead of blindly applying fixes.

### Guided Learning
- Provide progressive hints instead of immediately revealing solutions.
- Guide students through programming exercises.
- Encourage independent problem-solving.
- Help students understand code while building projects.

### Learning Progress
- Track concepts and topics practiced.
- Identify recurring mistakes.
- Highlight areas that need improvement.
- Help students understand their learning progress.

### Flux Library
- Pre-built project templates.
- Reusable UI components.
- Application starters.
- Code snippets.
- Community-contributed templates.

## 6. User Experience

The intended learning workflow:

1. Create or open a coding project.
2. Write code in the editor.
3. Run the code and observe the output.
4. Encounter an error or difficulty.
5. Receive contextual explanations and guidance.
6. Understand the concept and correct the mistake.
7. Continue building independently.

The objective is to keep learning and development within one environment.

## 7. Visual Design Direction

Flux follows a minimal, dark, developer-oriented interface.

**Design characteristics:**
- Dark theme with minimal visual distractions.
- Clean typography and clear visual hierarchy.
- Subtle borders and surface contrasts.
- Blue accents for interactive elements and highlights.
- Smooth animations and transitions.
- Responsive and consistent layouts.

## 8. AI Philosophy

AI in Flux should act as a programming tutor, not just a code generator.

Its purpose is to:
- Explain before automatically fixing.
- Guide before providing complete solutions.
- Adapt explanations to the learner's understanding.
- Encourage students to think and experiment.
- Help learners become less dependent on AI over time.

**The goal is not to make AI write code for students, but to help students learn how to write code themselves.**

## 10. Product Success

Flux should not measure success only through generated code, completed tasks, or development speed.

Its most important measure of success should be:

**How effectively does Flux help a student move from not understanding code to writing, debugging, and solving programming problems independently?**
